# 项目导火索(2019-2022)
- [忽略] 早期网吧限制(不算, 那时候作者还没出生!!!)
  - 2002 年 9 月 29 日，国务院公布《互联网上网服务营业场所管理条例》，明确规定互联网上网服务营业场所不得接纳未成年人进入，并应在入口处显著位置悬挂未成年人禁入标志，该条例于2002 年 11 月 15 日起施行。这是我国最早针对未成年人接触游戏（主要通过网吧）的全国性法规限制。 
- [次要导火索] 2019年10月25日：国家新闻出版署印发《关于防止未成年人沉迷网络游戏的通知》，自2019年11月01日起施行.
  - 每日22时至次日8时，不得为未成年人提供游戏服务
  - 法定节假日每日累计不超过3小时，其他时间每日累计不超过**1.5**小时
  - 必须实名注册，不得向未实名用户提供游戏服务
- [核心导火索] 2021年08月30日：国家新闻出版署发布《关于进一步严格管理切实防止未成年人沉迷网络游戏的通知》，被称为 "最严防沉迷新规".
  - 仅可在**周五、周六、周日**和法定节假日**每日20时至21时**向未成年人提供**1小时**服务
  - 所有网络游戏必须接入国家防沉迷实名验证系统，不得以任何形式向未实名用户提供游戏服务
> 后期的堪称军事化限制, 进一步加剧了熙柠游戏端的诞生
